# Public repository review checklist

- [ ] Obtain permission to name the organisation or use its branding; otherwise anonymise both.
- [ ] Remove employee names, addresses, IDs linked to real people and identifiable campaign results.
- [ ] Remove live tracking tokens and participant-specific links, including URLs embedded in HTML.
- [ ] Remove SMTP passwords, API keys, bearer headers, credentials and environment files.
- [ ] Review Git history, not just the latest files, for accidentally committed secrets.
- [ ] Redact screenshots and remove browser tabs, account details and personal information.
- [ ] Confirm code examples are labelled accurately and not presented as production source.
- [ ] Do not publish live administrative endpoints or operational access instructions.
- [ ] Review campaign findings for authorisation and privacy before publication.
