# Source code

This directory contains a sanitised copy of the Cloudflare Worker
used in CyberLab 002.

The Worker handles campaign enrolment, personalised training links,
interaction tracking and reporting through Cloudflare D1.

Organisation-specific URLs have been replaced with examples.
Credentials, participant records and tracking tokens are excluded.

The source reflects the Worker v4.0 implementation copied from
Cloudflare.
